Redis Keys Structure:
┌────────────────────────────────────────┐
│ mood_diary:fsm:state:{user_id}  [TTL]  │ ← Текущее состояние FSM
│ mood_diary:fsm:data:{user_id}   [TTL]  │ ← Данные диалога
│ cache:{key}                     [TTL]  │ ← Кэш (опционально)
└────────────────────────────────────────┘

Порядок запуска:
1. docker compose up -d redis
2. Redis healthcheck: ✓ PONG
3. Bot starts → RedisConnection.connect()
4. Connection pool created
5. FSM storage initialized
6. Bot polling starts ✓
